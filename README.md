# ИКП · Группа компаний «Человек»

Две отдельные панели: `/manager` для авторизованного менеджера и `/p/<секретная-ссылка>` для руководителя предприятия. Python 3.12, Waitress WSGI, SQLite WAL, HTML/CSS/JavaScript без сборки фронтенда. Стек следует подходу соседнего `ai_project`, его данные и секреты не копируются.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --create-user manager1
.\.venv\Scripts\python.exe run.py
```

Откройте http://localhost:8000/manager. Пароль задаётся интерактивно, минимум 12 символов. Стандартных аккаунтов и паролей нет. Для разработки без внешних зависимостей доступен `run.py --dev` (только loopback).

## Админ-панель

Адрес: `/admin`. Первый администратор создаётся владельцем сервера:

```powershell
.\.venv\Scripts\python.exe run.py --create-admin admin
```

В Docker: `docker compose exec app python run.py --create-admin admin`.
Пароль вводится интерактивно; автоматических администраторов и стандартных паролей нет. Существующий логин нельзя использовать повторно. После входа администратор автоматически попадает в `/admin`.

Администратор создаёт менеджеров и управляет тремя настройками: доступ к панели, создание/редактирование собственных КП, публикация и отзыв собственных ссылок. Активный менеджер всегда может просматривать свои КП и заявки. Права редактирования и публикации независимы. Через отдельную форму можно установить новый пароль (12–256 символов).

При создании и редактировании аккаунта администратор заполняет фамилию, имя, телефон, фото и аккаунты мессенджеров менеджера. Менеджер может самостоятельно изменить эти данные в окне «Мой профиль». Поддерживаются Telegram (`@имя` или ссылка `t.me`), WhatsApp (номер или ссылка `wa.me`), MAX (ссылка профиля `max.ru`) и другие HTTPS-ссылки. Эти данные автоматически копируются в каждое новое КП; отдельной кнопкой менеджер может применить профиль к открытому КП. В конкретном КП контакты можно изменить без изменения профиля.

Изменение доступа или пароля завершает все сессии этого менеджера. Блокировка не удаляет его предложения и не отзывает клиентские ссылки. Менеджеры не имеют доступа к административному API. Администратор управляет аккаунтами, но не получает доступ к КП через менеджерский API. Создание администраторов доступно только через CLI; форма панели создаёт только менеджеров. Изменения фиксируются в таблице `audit` без паролей. Схема базы обновляется при запуске до версии 5 с сохранением существующих пользователей как менеджеров с прежними полными правами.

## Docker и эксплуатация

1. Скопируйте `.env.example` в `.env`, укажите `PUBLIC_ORIGIN=https://ваш-домен` без завершающего `/`.
2. `docker compose up -d --build`.
3. `docker compose exec app python run.py --create-user manager1`.
4. Настройте HTTPS reverse proxy на `127.0.0.1:8000`, сохраняя Host и Origin. Приложение не доверяет произвольным forwarded-заголовкам. Ограничьте частоту запросов и размер тела также на прокси. За общим reverse proxy встроенный лимит входа применяется к его IP; задайте пер-IP лимит на самом прокси.
5. Проверьте `/healthz`, вход, публикацию, открытие ссылки с другого устройства и отправку заявки.

SQLite рассчитан на один экземпляр приложения с локальным постоянным диском. Не размещать базу на OneDrive/NFS и не масштабировать контейнер горизонтально с одной базой. Для нескольких экземпляров нужна миграция на PostgreSQL. Локальный путь базы переопределяется `DATABASE_PATH`.

Резервная копия: `python scripts/backup.py /путь/backup.sqlite3`. Используется SQLite backup API с проверкой целостности. Восстановление: остановите приложение, сохраните текущую базу отдельно, замените её проверенной резервной копией; убедитесь, что старые WAL/SHM не используются. Регулярно проверяйте восстановление. Резервные копии содержат персональные данные и требуют ограничения доступа и шифрования на уровне инфраструктуры.

## Поведение

- Менеджер создаёт и явно сохраняет черновик, настраивает цену и доступность каждой услуги, загружает фото и публикует снимок условий по персональной ссылке. Любую включённую услугу можно зафиксировать: клиент увидит её, но не сможет отключить. Одну включённую услугу можно отметить звездой как рекомендованную; на клиентской странице она выделяется, но остаётся отключаемой. Поле ИНН проверяется на 10/12 цифр; проверка по ФНС не подключена.
- Ссылка начинается с ИНН предприятия, а если он не заполнен — с короткого названия латиницей. После читаемого префикса сохраняется 256-битный случайный токен; в базе хранится только SHA-256 полной адресной части. Полная ссылка показывается при создании, сохраните её для отправки. Ссылка даёт доступ любому её получателю. Менеджер может отозвать каждую ссылку отдельно.
- Руководитель меняет число сотрудников и предложенные услуги, добавляет исследования и пожелания. Кнопки мессенджеров в карточке менеджера открывают соответствующий чат в новой вкладке или приложении. Первые два чек-апа печени/почек бесплатны. Расчёт производится в целых копейках, окончательная сумма проверяется сервером. Отключённые менеджером услуги клиент подключить не может.
- После отправки заявка сохраняется неизменно, повторная отправка возвращает ту же квитанцию. Перезагрузка ссылки показывает сохранённую заявку. Несохранённый клиентский выбор до отправки не сохраняется.
- Менеджер видит просмотры ссылок и заявки с составом и суммой; кнопка «Обновить» запрашивает актуальные данные. Новая публикация создаёт отдельную ссылку и отдельную возможность подачи заявки.
- Изменения черновика не изменяют опубликованные условия. Конфликт версий при редактировании в нескольких вкладках отклоняется сервером.
- Сессии менеджеров — HttpOnly/SameSite cookie, Secure на HTTPS, срок 8 часов. Пароли scrypt, защита от CSRF, лимит входа, CSP, отсутствие внешних скриптов и шрифтов, аудит операций в таблице `audit`.
- Печать / сохранение в PDF через системный диалог браузера включает выбранные услуги и итог.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check static/manager.js
node --check static/client.js
node tests/pricing.mjs
```

Исходный HTML находится в `docs/source-mvp.html` исключительно как референс. Он не обслуживается сервером. Каталог и логотип перенесены из него. В исходнике не было рабочих URL презентаций и корпоративного прайса, интеграции тестового доступа или доставки уведомлений. Эти интеграции не имитируются: результатом отправки является сохранённая заявка в панели менеджера. Автоматическая выдача пятидневного доступа, CRM и уведомления потребуют адресов сервисов и авторизации.

Перед публичным запуском нужны реальный домен и HTTPS, настройки резервного копирования и мониторинга, проверка реквизитов/контактов и актуального состава услуг владельцем продукта, а также нагрузочная проверка на целевой инфраструктуре. Проект не был опубликован и не подключён к боевым данным.

Вход осуществляется по логину и паролю. Логин не требует почты: например, `ivanov` или `manager1`. Допустимы 3–254 латинских символа, цифры и знаки `_ . - @ +`; регистр не учитывается. У существующих аккаунтов прежний email сохраняется как логин, пароли и права не изменяются.

## Подсказки организаций по ИНН

В форме предложения ИНН вводится первым. После четырёх цифр сервер запрашивает активные организации через DaData; при выборе подсказки заполняются полный ИНН и название. Ключ провайдера остаётся только на сервере. Укажите `DADATA_API_KEY` в `.env`: файл загружается и при локальном запуске, и через Docker Compose. Значения, явно заданные в окружении процесса, имеют приоритет над `.env`. После изменения файла перезапустите приложение. Без ключа форма продолжает работать, но список подсказок будет пустым. Запросы ограничены по частоте и кэшируются на час; адрес, КПП и другие сведения от провайдера не сохраняются.
